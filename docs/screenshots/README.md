# Threadline Application Screenshots

This directory is designated for authentic application screenshots captured from the live deployment or local development environment.

## Planned Screenshot Artifacts

1. `overview-dashboard.png` — Dashboard showing cross-project statistics, recent activity feed, and continuity status.
2. `project-workspace.png` — Project workspace interface displaying tasks, decisions, timeline, and document tabs.
3. `document-upload.png` — Ingestion interface showing PDF/DOCX file upload, file validation, and extraction progress.
4. `ai-review-queue.png` — Human-in-the-loop review queue showing extracted claims, confidence scores, evidence snippets, and page citations.
5. `continuity-map.png` — Interactive relational continuity graph showing tasks, decisions, ownership connections, orphan nodes, and blocking paths.
6. `handover-report.png` — Generated 11-section handover document with incoming successor role assignment and PDF export button.

When adding images, ensure they are captured at high resolution (1920x1080 or 1440x900) with sensitive tokens or credentials excluded.
